The brief

A property management company with 200+ units was handling maintenance requests manually — calls, texts, and spreadsheets. They needed every request automatically classified, prioritised, and dispatched without anyone touching it.

02 /

The plan I drafted

  • Accept requests from web, SMS and email in one pipeline
  • Let AI classify priority and trade
  • Route to the best available contractor automatically
  • Keep tenants and managers informed without phone calls
03 /

The process, step by step

Full n8n workflow canvas: inbound request trigger (web form / SMS / email) → Claude AI triage (P0 emergency / P1 urgent / P2 routine) → contractor routing (by skill, availability, and proximity) → work order generation → tenant notification → completion follow-up.

  1. Inbound Request Capture

    Three entry points: web form, SMS keyword, and forwarded email. All normalised into a single request object before entering the triage pipeline.

  2. Claude Triage Node

    Request text sent to Claude with a triage prompt. Claude returns: priority level (P0/P1/P2), issue category (plumbing/electrical/HVAC/structural), and an urgency rationale.

  3. Contractor Routing

    Based on Claude's classification, the workflow queries an Airtable contractor database and selects the best match by skill, availability (Google Calendar API), and geo-proximity.

  4. Work Order & Notifications

    PDF work order auto-generated and sent to contractor. Tenant receives an SMS with estimated response time. Property manager gets a daily digest of all active orders.

04 /

The bottleneck

! bottleneckTenants describe problems vaguely

Free-text requests like 'water everywhere' or 'heater weird' are hard to classify reliably.

05 /

How I fixed it

✓ fix

Claude returns a structured result — priority, category and a short rationale — so every decision is explainable and consistent before the routing step runs.

06 /

The result

  • Average time from request to contractor assignment reduced from 4 hours to 11 minutes
  • P0 emergencies (floods, no heat) now escalated and contacted within 3 minutes
  • Staff time on maintenance coordination reduced by 70% — from 3 hours/day to under 30 minutes
