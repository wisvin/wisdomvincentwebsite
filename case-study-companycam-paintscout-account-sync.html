What the client came with

A painting contractor ran sales in their CRM (LeadConnector / GoHighLevel), photos and job sites in CompanyCam, and estimates in PaintScout. Every time a lead booked an estimate, someone re-typed the customer's details into both tools — slow, and easy to get wrong.

02 /

The plan I drafted

  • Trigger automatically when a lead moves to the booked-estimate stage in the CRM
  • Create the job in CompanyCam and the contact in PaintScout from the same data
  • Send a confirmation email so the team knows everything was created
03 /

The process, step by step

A Zapier automation that syncs account data between CompanyCam and PaintScout, so an update in one system is reflected in the other without anyone retyping it.

  1. Trigger on pipeline change

    A LeadConnector 'Pipeline Stage Changed' trigger starts the Zap the moment a lead's stage moves.

  2. Filter the right leads

    A Filter step only lets the Zap continue for the correct stage and when the contact has an email, so nothing half-complete gets created.

  3. Create the CompanyCam project

    The project is created with the customer's name and full address so the crew can start documenting the job straight away.

  4. Create the PaintScout contact

    The same customer record is created in PaintScout, ready for the estimate.

  5. Confirm by email

    An outbound email summarises what was created in both systems and the customer details used.

04 /

The bottleneck

! bottleneckEvery stage change fired the automation

The CRM trigger fires on every pipeline move, which would have created duplicate projects and contacts each time a lead moved stage.

05 /

How I fixed it

✓ fix

I added a filter so the Zap only continues for the booked-estimate stage and only when an email exists, then tested it with real test records through every path before switching it on.

06 /

The result

  • Manual data entry between the two platforms eliminated
  • Both platforms stay in sync automatically
  • The team gets a confirmation email for every new job
